🏋️ Fitness Time

Aplicación en C para la gestión de alimentación y entrenamiento, desarrollada como proyecto académico.

🚀 Funcionalidades
Registro y login de usuarios
Cálculo de calorías y macronutrientes según objetivos
Seguimiento de alimentación diaria (proteínas, carbohidratos y grasas)
Registro de entrenamientos (ejercicios, series y repeticiones)
⚙️ Ejecución
gcc *.c -o programa.exe
./programa.exe
📌 Notas

Proyecto de consola que utiliza estructuras y archivos para gestionar la información del usuario.
